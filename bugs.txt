  Complete End-to-End Business Scenario

  Test this full flow to validate the entire system:

  1. Admin sets up company with Karnataka state code (29)
  2. Admin creates product "Laptop" with 18% GST, selling price ₹50,000
  3. Admin creates customer "ABC Corp" (Karnataka)
  4. Admin creates supplier "XYZ Electronics" (Maharashtra)
  5. Inventory user creates PO for 10 Laptops @ ₹40,000 from supplier
  6. Inventory user creates GRN for 10 units → Stock becomes 10
  7. Sales user creates quotation for 2 Laptops to ABC Corp
  8. Sales user converts quotation to SO → confirms (stock check passes)
  9. Sales user creates invoice from SO → issues (stock becomes 8)
  10. Accounting user receives payment from ABC Corp → allocates to invoice
  11. Check dashboard: Today sales = ₹1,00,000, Stock = 8 units
  12. Check GSTR-1 report: CGST/SGST recorded for intra-state sale
